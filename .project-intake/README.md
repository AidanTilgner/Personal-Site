# Project intake inbox

Optionally create one subdirectory per project here and drop in notes, exports,
screenshots, photos, PDFs, links, and other source material. Everything except
this README is ignored by Git because intake material may be private or large.

Then give an agent this instruction:

> Create and preview a project page from `.project-intake/<folder>`. Follow
> `AGENTS.md` and `docs/project-intake.md`. Treat the folder as read-only source
> evidence and do not invent missing facts.

The source folder may live anywhere on the computer instead. Pass its absolute
path in the same prompt.
